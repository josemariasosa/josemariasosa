I was born in the desert of San Luis Potosí, México 🌵🇲🇽.

I am an engineer, builder, and quiet operator working near the intersection of backend systems, blockchain infrastructure, and financial primitives.

These days, most of my work lives inside **Iron Burrow**:  
a small but stubborn underground system for indexing chains, serving honest data, protecting nodes, and building tools for humans, bots, and agents.

The burrow has many rooms:

- **Sentinel** watches the surface.
- **Bigwig** guards the entrance.
- **Indexers** work underground.
- **Nodes** never meet strangers.

I like systems that are simple, transparent, and resilient.  
I like infrastructure that tells the truth about what it knows.  
I like software that feels like it was built by someone who cares.

Welcome to the burrow.
